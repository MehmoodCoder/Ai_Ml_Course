## 🛠️ Core Tech Stack & Libraries

To build and train models, I actively use and learn the following industry-standard Python libraries:

| Library | Purpose | What I Use It For |
| :--- | :--- | :--- |

| **🔢 NumPy** | Numerical Computing | Performing high-performance mathematical operations on multi-dimensional arrays. |
